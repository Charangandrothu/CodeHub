## 5. Cognizant GenC - Detailed Syllabus

### 5.1 Communication Assessment (40 minutes)

**⚠️ HIGHEST ELIMINATION ROUND - ~60% candidates fail here**

**Platform:** AI-based assessment (automated evaluation)  
**Sections:** 5 sections testing all language skills

---

#### Section 1: Reading Comprehension (10 questions, 8 minutes)

**Format:**
- 2-3 passages (150-200 words each)
- 3-4 questions per passage

**Question Types:**
1. Main idea
2. Inference
3. Vocabulary in context
4. Specific details

**Sample:**
```
Passage: (200 words on "Digital Transformation in Healthcare")

Q: What is the primary benefit of AI in healthcare mentioned in the passage?

A) Cost reduction
B) Early disease detection
C) Patient convenience
D) Doctor efficiency

Answer: B (based on passage content)
```

**Preparation:**
- Practice CAT/GRE level passages
- Read The Economist, Scientific American daily
- Focus on inference questions (most tricky)

---

#### Section 2: Listening Comprehension (10 questions, 8 minutes)

**Format:**
- 2-3 audio clips (conversations, lectures, announcements)
- Audio plays only ONCE (no replay)
- 3-4 questions per clip

**Question Types:**
1. Main idea of conversation
2. Specific details mentioned
3. Speaker's intention/tone
4. What happens next (prediction)

**Audio Types:**
- Office conversations
- Technical discussions
- News broadcasts
- Instructions/Announcements

**Preparation:**
- Listen to TED Talks, BBC podcasts
- Practice note-taking while listening
- Use YouTube videos with comprehension questions
- **CRITICAL:** Train yourself to focus (no second chance)

---

#### Section 3: Speaking Assessment (6 tasks, 12 minutes)

**Format:** AI-based voice recording and evaluation

**Task Types:**

1. **Read Aloud (2 tasks)**
   - Given a passage, read it clearly
   - Evaluated: Pronunciation, fluency, clarity
   - Time: 1 minute per task

2. **Describe Image (2 tasks)**
   - Given a graph/chart/image
   - Describe what you see in 40-50 seconds
   - Evaluated: Coherence, vocabulary, grammar

3. **Answer Short Question (2 tasks)**
   - Listen to a question, answer in 1 sentence
   - Time: 10 seconds to respond
   - Example: "What do you call a person who designs buildings?" → "An architect"

**Evaluation Criteria:**
- **Pronunciation:** 30%
- **Fluency:** 30%
- **Content:** 20%
- **Grammar:** 20%

**Common Mistakes:**
- Speaking too fast or too slow
- Mumbling words
- Using filler words (um, ah, like)
- Long pauses
- Incorrect pronunciation of common tech terms

**Preparation:**
- Record yourself daily (2 minutes)
- Practice describing images/graphs
- Learn pronunciation of tech terms:
  - Algorithm, Cache, Queue, Schema, Hierarchy
  - Database, Repository, Architecture, Deployment
  - Integer, Boolean, Variable, Function

---

#### Section 4: Writing Assessment (2 tasks, 10 minutes)

**Task 1: Email Writing (5 minutes)**
- **Scenario:** Write a professional email
- **Word Limit:** 50-75 words
- **Example:** 
  - "Write an email to your manager requesting leave for 2 days"
  - "Write to a client about project delay and propose solution"

**Evaluation:**
- Grammar and punctuation
- Professional tone
- Clear and concise
- Proper email format (Subject, Greeting, Body, Closing)

**Task 2: Sentence Writing (5 minutes)**
- **Given:** A situation or image
- **Task:** Write 2-3 sentences describing it
- **Word Limit:** 30-50 words

**Evaluation:**
- Sentence structure
- Vocabulary usage
- Relevance to topic

**Preparation:**
- Practice writing formal emails
- Learn email templates
- Review grammar rules (tenses, articles, prepositions)

---

#### Section 5: Typing Speed Test (1 passage, 2 minutes)

**Format:**
- Given a passage (100-150 words)
- Type it exactly as shown
- Time: 2 minutes

**Evaluation:**
- **Speed:** Words per minute (WPM)
- **Accuracy:** Percentage of correct characters
- **Minimum:** 30 WPM with 90% accuracy

**Preparation:**
- Practice on typing.com or 10fastfingers.com
- Target: 40-50 WPM with 95%+ accuracy
- Practice technical paragraphs (not just general text)

---

### 5.2 Game-Based Aptitude Assessment (24 games, 4 selected, 23 minutes)

**⚠️ UNIQUE TO COGNIZANT - Most Challenging & Unpredictable**

**Format:**
- Pool of 24 mini-games
- System randomly selects 4 games for you
- Each game tests different cognitive skills
- **Adaptive difficulty:** Gets harder if you perform well

**Time Distribution:**
- Game varies, typically 4-8 minutes per game
- Total: ~23 minutes for 4 games

---

#### Game Categories

**1. Numerical Games (8 games in pool)**

**Game Example 1: Number Grid**
```
Task: Find the missing number in a 3x3 grid
Time: 5 minutes for 10 grids

Grid:
  2   4   8
  3   9   27
  4   16  ?

Pattern: Column 2 = Column 1 squared, Column 3 = Column 1 cubed
Answer: 64
```

**Game Example 2: Fast Math**
```
Task: Solve simple calculations quickly
Time: 60 seconds for 15 problems

Example:
23 + 17 = ?
45 × 2 = ?
120 ÷ 6 = ?

Focus: Speed + Accuracy
```

**Game Example 3: Number Sequence**
```
Task: Identify next number in sequence
Time: 3 minutes for 8 sequences

Example: 2, 6, 12, 20, 30, ?
Pattern: +4, +6, +8, +10, (+12)
Answer: 42
```

---

**2. Logical Games (8 games in pool)**

**Game Example 1: Pattern Matching**
```
Task: Identify which pattern fits the sequence
Time: 5 minutes for 10 patterns

Given: □ ○ △ □ ○ ?
Options: △, □, ○, ◇
Answer: △ (repeating pattern)
```

**Game Example 2: Odd One Out**
```
Task: Identify which item doesn't belong
Time: 4 minutes for 12 sets

Example:
Set: Dog, Cat, Elephant, Car, Lion
Odd one: Car (only non-animal)
```

**Game Example 3: Rotation/Mirror**
```
Task: Identify rotated or mirrored shapes
Time: 6 minutes for 15 shapes

Given a shape, identify if Option A/B/C/D is:
- Same shape rotated
- Mirror image
- Different shape
```

---

**3. Verbal Games (4 games in pool)**

**Game Example 1: Word Association**
```
Task: Choose the word most related to given word
Time: 3 minutes for 15 pairs

Example:
Hot : ?
Options: Cold, Fire, Ice, Summer
Answer: Cold (antonym)
```

**Game Example 2: Vocabulary Builder**
```
Task: Choose correct meaning of word
Time: 4 minutes for 20 words

Example:
Benevolent means:
A) Hostile  B) Kind  C) Wealthy  D) Intelligent
Answer: B
```

---

**4. Spatial Games (4 games in pool)**

**Game Example 1: Shape Folding**
```
Task: Identify which 3D shape is formed when a 2D net is folded
Time: 6 minutes for 10 shapes

Given: A flat cross-shaped net
Question: Which cube does it form?
(Shows 4 different cubes with different face patterns)
```

**Game Example 2: Direction Navigation**
```
Task: Navigate a grid based on instructions
Time: 5 minutes for 8 navigation tasks

Example:
Start at (0,0)
Move: Right 3, Up 2, Left 1, Down 3
Final position: ?
Answer: (2, -1)
```

---

#### How Games are Evaluated

**Scoring System:**
- **Speed:** How quickly you complete
- **Accuracy:** Percentage of correct answers
- **Consistency:** Performance across all 4 games
- **Adaptive Performance:** How well you handle increasing difficulty

**Percentile Calculation:**
- Your score compared to all test-takers
- Cut-off: Typically 60-65 percentile
- Top performers (80+ percentile) → considered for GenC Pro/Next

---

#### Game-Based Aptitude Strategy

**Before the Test:**
1. **Practice brain training apps:**
   - Lumosity
   - Peak
   - Elevate
   - CogniFit

2. **Play similar games:**
   - Sudoku (number logic)
   - Chess (strategy)
   - Pattern recognition puzzles
   - Math puzzles

3. **Familiarize with interface:**
   - Practice on Superset platform if demo available
   - Understand navigation (Next, Skip, Submit)

**During the Test:**
1. **Read instructions carefully** (each game has different rules)
2. **Don't panic if a game seems hard** (it's adaptive - hard = you're doing well)
3. **Manage time:** Don't spend too long on one question
4. **Accuracy > Speed:** But maintain reasonable pace
5. **Stay calm:** These games test cognitive ability under pressure

**Pro Tip:** The games are designed to be unfamiliar. Your ability to **learn quickly** and **adapt** is what's being tested, not prior knowledge.

## 7. Technical Clusters

### Cluster 1: Java + Web Development

**Focus:** 85% questions on Java and SQL, 15% on Web (HTML/CSS/JS)

#### Section 1: Java Programming (40-45 minutes)

**Question Types:**
1. **Java MCQs (15-20 questions)**
   - OOP concepts (Inheritance, Polymorphism, Encapsulation, Abstraction)
   - Exception Handling
   - Collections Framework (ArrayList, HashMap, HashSet)
   - Multithreading basics
   - String manipulation

2. **Code Output Questions (5-10 questions)**
   - Predict output of given code
   - Identify errors in code

3. **Code Debugging (2-3 questions)**
   - Find and fix bugs in given code

**Sample Java MCQ:**
```
Q: What is the output?

class Test {
    public static void main(String[] args) {
        String s1 = "Hello";
        String s2 = "Hello";
        String s3 = new String("Hello");
        
        System.out.println(s1 == s2);
        System.out.println(s1 == s3);
    }
}

A) true, true
B) true, false ✓
C) false, true
D) false, false

Explanation: s1 and s2 refer to same object in string pool. s3 is new object.
```

---

#### Section 2: ANSI SQL (35-40 minutes)

**Question Types:**
1. **SQL Query Writing (10-12 questions)**
   - SELECT with WHERE, ORDER BY, GROUP BY
   - JOINs (INNER, LEFT, RIGHT)
   - Aggregate functions (COUNT, SUM, AVG, MAX, MIN)
   - Subqueries
   - HAVING clause

2. **SQL Output Questions (5-8 questions)**
   - Given table data and query, predict output

3. **Database Concepts (3-5 questions)**
   - Normalization (1NF, 2NF, 3NF)
   - Primary Key, Foreign Key
   - ACID properties
   - Indexes

**Sample SQL Question:**
```
Table: Employees
EmpID | Name    | Salary | DeptID
1     | Alice   | 50000  | 10
2     | Bob     | 60000  | 20
3     | Charlie | 55000  | 10
4     | David   | 70000  | 20

Q: Write a query to find the average salary per department.

Answer:
SELECT DeptID, AVG(Salary) AS AvgSalary
FROM Employees
GROUP BY DeptID;

Output:
DeptID | AvgSalary
10     | 52500
20     | 65000
```

**Sample JavaScript Question:**
```

B) 20 ✓
C) undefined
D) Error

Explanation: Closure - inner() has access to outer()'s variable x = 20.
```

- Technologies used and your specific role

**For Cluster 1 (Java):**
- Explain OOP pillars with real-world examples

**For Cluster 2 (Python):**
- List vs Tuple vs Set vs Dictionary
- Generators and iterators
- Decorators

- PEP 8 standards

**For All Clusters (SQL - Mandatory):**
- Normalization with examples
- Types of JOINs with scenarios
- Difference between WHERE and HAVING

**Common CS Fundamentals:**
- **DBMS:** Transactions, locking, deadlock

- **Networks:** OSI layers, TCP vs UDP, HTTP methods
- **OOP:** Real-world examples of concepts

#### 3. Coding Problem (Live, 5-10 min)
- 1 easy-medium coding problem
- Write code on paper/whiteboard/editor
- Explain approach first, then code

**Sample Questions:**
- Reverse a string without library function
- Find duplicates in an array
- Check if a number is prime
- Fibonacci series (iterative and recursive)

- "Tell me about yourself"
- "Why Cognizant?"

### 10.2 SQL - Sample Questions

#### Q1: JOIN Query

```
Tables:
Students: (StudentID, Name, DeptID)
Departments: (DeptID, DeptName)

Q: Write a query to display student names with their department names.

Answer:
SELECT s.Name, d.DeptName
FROM Students s
INNER JOIN Departments d
ON s.DeptID = d.DeptID;
```

---

#### Q2: GROUP BY with HAVING

```
Table: Sales (ProductID, ProductName, Quantity, Price)

Q: Find products with total sales value greater than $10,000.

Answer:
SELECT ProductName, SUM(Quantity * Price) AS TotalSales
FROM Sales
GROUP BY ProductName
HAVING SUM(Quantity * Price) > 10000;
```

### 10.3 Java - Sample Questions

#### Q3: OOP Concept

```
Q: What is the output?

class Animal {
    void sound() {
        System.out.println("Animal makes sound");
    }
}

class Dog extends Animal {
    void sound() {
        System.out.println("Dog barks");
    }
}

public class Test {
    public static void main(String[] args) {
        Animal a = new Dog();
        a.sound();
    }
}

A) Animal makes sound
B) Dog barks ✓
C) Compilation error
D) Runtime error

Explanation: Runtime polymorphism - method overriding. Object type is Dog, so Dog's sound() is called.
```
