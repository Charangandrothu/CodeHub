## 5. Cognitive Assessment - Detailed Syllabus

**Duration:** 90 minutes (shared across all 3 sections)  
**Total Questions:** 50  
**Difficulty:** Moderate to Hard (Adaptive)

### 5.1 English Ability (17 questions)

**⚠️ Adaptive Section - Difficulty increases if you perform well**

#### Topic Breakdown

| Topic | Questions | Priority | Difficulty |
|-------|-----------|----------|------------|
| Reading Comprehension | 5-6 | **Very High** | Medium |
| Sentence Correction/Error Spotting | 4-5 | High | Medium |
| Fill in the Blanks | 3-4 | High | Easy-Medium |
| Vocabulary (Synonyms/Antonyms) | 2-3 | Medium | Easy-Medium |
| Para Jumbles | 1-2 | Medium | Hard |

#### Detailed Coverage

##### 1. Reading Comprehension

**Format:**
- 1-2 passages (200-300 words each)
- 3-4 questions per passage

**Passage Topics:**
- Technology & Innovation (AI, Cloud, IoT, Blockchain)
- Business & Management
- Environmental issues
- Social topics

**Question Types:**
1. Main idea/central theme
2. Inference (author's implication)
3. Vocabulary in context
4. Specific details
5. Author's tone/purpose

**Sample:**
```
Passage: (250 words on "Blockchain in Supply Chain Management")

Q: According to the passage, what is the primary advantage of blockchain in supply chain?

A) Cost reduction
B) Transparency and traceability ✓
C) Faster delivery
D) Reduced manpower

Answer: B
```

---

##### 2. Sentence Correction

**Error Types:**
1. Subject-Verb Agreement
2. Tense Consistency
3. Pronoun-Antecedent Agreement
4. Modifier Errors
5. Parallel Structure

**Sample:**
```
Q: The team have completed their project ahead of schedule.

Find the error:

A) The team
B) have completed ✓
C) their project
D) No error

Explanation: "Team" is collective noun, takes singular verb "has"
```

### 5.2 Critical Reasoning & Problem Solving (18 questions)

**⚠️ HARDEST SECTION - Highest elimination rate**

#### Topic Breakdown

| Topic | Questions | Priority | Difficulty |
|-------|-----------|----------|------------|
| Syllogisms | 3-4 | **Very High** | Hard |
| Logical Deduction | 3-4 | **Very High** | Medium-Hard |
| Analytical Puzzles | 3-4 | **Very High** | Hard |
| Data Sufficiency | 2-3 | High | Medium |
| Statement & Assumptions/Conclusions | 2-3 | High | Medium |
| Critical Thinking | 2-3 | High | Hard |

#### Detailed Coverage

##### 1. Syllogisms

**Types:**
- All/Some/No statements
- Negative conclusions
- Complementary pairs
- Either-or cases

**Sample:**
```
Statements:
1. All developers are programmers.
2. Some programmers are engineers.

Conclusions:
I. Some developers are engineers.
II. Some engineers are programmers.

A) Only I follows
B) Only II follows ✓
C) Both follow
D) Neither follows

Explanation: Conclusion II is converse of statement 2 (always true).
Conclusion I cannot be determined.
```

---

##### 2. Analytical Puzzles

**Types:**
- Seating arrangements (linear, circular)
- Floor-based puzzles
- Scheduling (day/month assignment)
- Profession/color/hobby assignment

**Sample:**
```
Five friends A, B, C, D, E are sitting in a row.
- A and B are not sitting together
- C is sitting between D and E
- D is second from left end

Arrangement: D C E A B

Question: Who is sitting at the right end?

Answer: B
```

---

##### 3. Data Sufficiency

**Sample:**
```
Question: What is John's age?

Statements:
A. John is 5 years older than Mary.
B. Mary is 25 years old.

A) Statement A alone is sufficient
B) Statement B alone is sufficient
C) Both together are sufficient ✓
D) Neither is sufficient

Explanation: Need both statements to calculate John's age = 30.
```

### 5.3 Abstract Reasoning (15 questions)

**⚠️ MOST CHALLENGING - Tests pattern recognition & spatial ability**

**Time Pressure:** ~1 minute per question (very tight)

#### Topic Breakdown

| Type | Questions | Priority | Difficulty |
|------|-----------|----------|------------|
| Pattern Completion | 4-5 | **Very High** | Hard |
| Figure Series | 3-4 | High | Medium-Hard |
| Odd One Out | 2-3 | High | Medium |
| Mirror/Rotation Images | 2-3 | High | Medium-Hard |
| Analogy (Figure-based) | 2-3 | Medium | Medium |

#### Sample Questions

##### Type 1: Pattern Completion

```
Given: A 3x3 grid with 8 cells filled with patterns/shapes

Task: Identify which option completes the 9th cell

Options: 4 different patterns shown

Logic: Look for row-wise, column-wise, or diagonal patterns
- Shapes change (circle → square → triangle)
- Shading changes (filled → empty)
- Rotation (90° clockwise)
```

---

##### Type 2: Figure Series

```
Given: ◯ ◐ ◑ ◕ ?

Options:
A) ◯
B) ◐
C) ● ✓
D) ◕

Pattern: Circle filling clockwise (0% → 25% → 50% → 75% → 100%)
```

---

##### Type 3: Mirror Images

```
Given: Letter "F"

Question: Which option shows mirror image along vertical axis?

Answer: Reversed "F" (Ⅎ)
```

---

**Preparation Tips:**
- Practice IQ test patterns daily
- Use apps: Lumosity, Peak (Abstract reasoning games)
- Practice 100+ abstract reasoning problems
- Learn common patterns:
  - Rotation (90°, 180°, 270°)
  - Reflection (horizontal, vertical)
  - Shading changes
  - Shape morphing
  - Number of elements increasing/decreasing

**Code Format:** C-like syntax or Python-like syntax

### 7.3 Sample Coding Problems

#### Problem 1 (Easy): Array Problem

```
Title: Find Missing Number in Array

Description:
Given an array containing n distinct numbers from 1 to n+1, find the missing number.

Input:
arr = [1, 2, 4, 5, 6]
n = 5

Output:
3

Explanation:
Numbers 1 to 6 are expected, 3 is missing.

Constraints:
- 1 ≤ n ≤ 10^5
- Array contains distinct numbers

Starter Code (Python):
def findMissing(arr, n):
    # Write your code here
    pass

Test Cases:
Input: [1, 2, 4, 5, 6], n=5
Output: 3

Input: [2, 3, 4, 5], n=4
Output: 1
```

**Solution:**
```python
def findMissing(arr, n):
    # Method 1: Using sum formula
    expected_sum = (n + 1) * (n + 2) // 2
    actual_sum = sum(arr)
    return expected_sum - actual_sum

# Method 2: Using XOR (more efficient)
def findMissingXOR(arr, n):
    xor_all = 0
    xor_arr = 0
    
    # XOR all numbers from 1 to n+1
    for i in range(1, n + 2):
        xor_all ^= i
    
    # XOR all array elements
    for num in arr:
        xor_arr ^= num
    
    # Missing number
    return xor_all ^ xor_arr

# Time: O(n), Space: O(1)
```

#### Problem 2 (Medium): String Problem

```
Title: First Non-Repeating Character

Description:

Output:
1

Explanation:
'c' is the first character that appears only once (index 1).

Constraints:
```

**Solution:**
```python
def firstNonRepeating(s):
    # Count frequency of each character
    freq = {}
    for char in s:
        freq[char] = freq.get(char, 0) + 1
    
    # Find first character with frequency 1
    for i, char in enumerate(s):
        if freq[char] == 1:
            return i
    
    return -1

# Time: O(n), Space: O(n)
```

### 11.3 Coding - Sample Solution

```python
# Problem: Check if string is palindrome

def isPalindrome(s):
    # Remove non-alphanumeric and convert to lowercase
    cleaned = ''.join(c.lower() for c in s if c.isalnum())
    
    # Two pointer approach
    left, right = 0, len(cleaned) - 1
    
    while left < right:
        if cleaned[left] != cleaned[right]:
            return False
        left += 1
        right -= 1
    
    return True

# Test
print(isPalindrome("A man, a plan, a canal: Panama"))  # True
print(isPalindrome("race a car"))  # False

# Time: O(n), Space: O(n)
```
