**Sample Question:**
```
Q: A shopkeeper allows a discount of 10% on the marked price. How much above the cost 
price must he mark his goods to gain 8%?

A) 18%    B) 20%    C) 22%    D) 25%

Solution:
Let CP = 100
Required SP for 8% profit = 108

Let MP = x
After 10% discount: SP = 0.9x
0.9x = 108
x = 120

Mark above CP = 120 - 100 = 20%

Answer: B
```

##### 2. Time & Work

**Concepts:**
- Individual and combined work
- Pipes and cisterns
- Work efficiency (LCM method)

**Sample Question:**
```
Q: A can do a piece of work in 15 days and B in 20 days. They work together for 4 days, 
then A leaves. In how many more days will B finish the remaining work?

A) 10 days    B) 11 days    C) 12 days    D) 13 days

Solution:
A's 1 day work = 1/15
B's 1 day work = 1/20
Together = 1/15 + 1/20 = 7/60

Work done in 4 days = 4 × 7/60 = 28/60 = 7/15
Remaining = 1 - 7/15 = 8/15

B completes 8/15 in: (8/15) / (1/20) = (8/15) × 20 = 32/3 = 10.67 ≈ 11 days

Answer: B
```

##### Problem 1 (Easy): Array Manipulation

```
Title: Find the Kth Largest Element in an Array

Description:
Given an unsorted array of integers, find the kth largest element.

Input:
arr = [3, 2, 1, 5, 6, 4]
k = 2

Output:
5

Explanation:
When sorted in descending order: [6, 5, 4, 3, 2, 1]
2nd largest = 5

Constraints:
- 1 ≤ arr.length ≤ 10^4
- -10^4 ≤ arr[i] ≤ 10^4
- 1 ≤ k ≤ arr.length

Starter Code (Python):
def findKthLargest(arr, k):
    # Write your code here
    pass

Test Cases:
Input: arr = [3,2,1,5,6,4], k = 2
Output: 5

Input: arr = [3,2,3,1,2,4,5,5,6], k = 4
Output: 4
```

**Solution:**
```python
def findKthLargest(arr, k):
    # Simple approach: sort and return
    arr.sort(reverse=True)
    return arr[k-1]

# Optimal: Using heap (for large arrays)
import heapq
def findKthLargestOptimal(arr, k):
    return heapq.nlargest(k, arr)[-1]

# Time: O(n log n) for sort, O(n log k) for heap
# Space: O(1) for sort, O(k) for heap
```

def isRotation(s1, s2):

    return s2 in combined

# s1+s1 = "waterbottlewaterbottle"
# s2 = "erbottlewat" is present in above

##### Problem 3 (Medium): Array Problem

```
Title: Find the Majority Element

Description:
Given an array of size n, find the majority element. The majority element is the element 
that appears more than n/2 times. You may assume that the majority element always exists.

Input:
arr = [3, 2, 3]

Output:
3

Explanation:
3 appears 2 times, which is more than 3/2 = 1.5

Constraints:
- 1 ≤ n ≤ 5 * 10^4
- -10^9 ≤ arr[i] ≤ 10^9

Starter Code (Python):
def majorityElement(arr):
    # Write your code here
    pass

Test Cases:
Input: [3,2,3]
Output: 3

Input: [2,2,1,1,1,2,2]
Output: 2
```

**Solution:**
```python
# Approach 1: Hashing (Easy to understand)
def majorityElement(arr):
    count = {}
    n = len(arr)
    
    for num in arr:
        count[num] = count.get(num, 0) + 1
        if count[num] > n // 2:
            return num
    
    return -1

# Time: O(n), Space: O(n)

# Approach 2: Boyer-Moore Voting Algorithm (Optimal)
def majorityElementOptimal(arr):
    candidate = None
    count = 0
    
    # Phase 1: Find candidate
    for num in arr:
        if count == 0:
            candidate = num
        count += (1 if num == candidate else -1)
    
    # Phase 2: Verify candidate (if not guaranteed to exist)
    # count = sum(1 for num in arr if num == candidate)
    # return candidate if count > len(arr) // 2 else -1
    
    return candidate

# Time: O(n), Space: O(1)
```

## 8. Sample Questions by Topic

### 8.1 Quantitative Aptitude Questions

#### Q1: Percentages

```
Q: A number is increased by 20% and then decreased by 20%. What is the net change?

A) No change    B) 4% decrease    C) 4% increase    D) 2% decrease

Solution:
Let original number = 100

After 20% increase: 100 × 1.20 = 120
After 20% decrease: 120 × 0.80 = 96

Net change = 96 - 100 = -4 (decrease)
Percentage = 4%

Answer: B
```

---

#### Q2: Time & Work

```
Q: A and B can complete a work together in 12 days. A alone can complete it in 20 days. 
In how many days can B alone complete the work?

A) 25 days    B) 28 days    C) 30 days    D) 32 days

Solution:
(A + B)'s 1 day work = 1/12
A's 1 day work = 1/20

B's 1 day work = 1/12 - 1/20 = (5-3)/60 = 2/60 = 1/30

B alone = 30 days

Answer: C
```

### 8.2 Logical Reasoning Questions

#### Q3: Blood Relations

```
Q: A is the father of C. But C is not the son of A. How is C related to A?

Solution:
If C is not the son of A, but A is C's father, then C must be female.

Answer: B (Daughter)
```

#### Q4: Coding-Decoding

```
Q: In a certain code, "WIPRO" is written as "XJQSP". How is "ELITE" written in that code?

A) FMJUF    B) FMJUF    C) EMJUF    D) FMKTF

Solution:
Pattern: Each letter is shifted by +1
W → X, I → J, P → Q, R → S, O → P

Similarly:
E → F, L → M, I → J, T → U, E → F

Answer: A (FMJUF)
```

### 8.4 Coding Questions

#### Q7: Array Problem

```
Q: Given an array of integers, find the first repeating element.

Input: [10, 5, 3, 4, 3, 5, 6]
Output: 5

Explanation: 
5 appears at index 1 and 5 (repeats first among all repeating elements)

Python Solution:
def firstRepeating(arr):
    seen = set()
    for num in arr:
        if num in seen:
            return num
        seen.add(num)
    return -1

# Time: O(n), Space: O(n)
```
