## 1. Overview

**TCS NQT (National Qualifier Test)** is TCS's standardized assessment for hiring fresh engineering graduates across India.

**Key Facts:**
- Multiple drives per year (3-4 times annually)
- Two-tier exam: Foundation (mandatory) + Advanced (for higher packages)
- No negative marking in any section
- Online proctored test
- Results typically within 2-3 weeks

---

## 2. Exam Structure

### Foundation Section (75 minutes)
| Section | Questions | Time | Difficulty |
|---------|-----------|------|------------|
| Numerical Ability | 20 | 25 min | Easy-Medium |
| Verbal Ability | 25 | 25 min | Easy-Medium |
| Reasoning Ability | 20 | 25 min | Medium |
| **Total** | **65** | **75 min** | - |

### Advanced Section (115 minutes)
| Section | Questions | Time | Difficulty |
|---------|-----------|------|------------|
| Advanced Quantitative | 15 | 25 min | Medium-Hard |
| Advanced Reasoning | 10 | 0 min* | Hard |
| Advanced Coding | 2 | 90 min | Medium |
| **Total** | **27** | **115 min** | - |

*Time is shared across sections

**Important Notes:**
- Foundation section is **mandatory** for all roles
- Advanced section is **optional but highly recommended** for TCS Digital/Prime
- Both sections taken in the same sitting with a short break
- Auto-submit when timer ends

## 3. Eligibility Criteria

### Academic Requirements
- **Degree:** B.Tech/B.E/M.Tech/M.E/MCA/M.Sc/MS (AICTE/UGC approved)
- **Branches:** All engineering branches eligible
- **CGPA:** Minimum 60% or 6.0 CGPA across:
  - Class 10th
  - Class 12th / Diploma
  - Graduation (BE/B.Tech)
  - Post-Graduation (if applicable)

### Additional Criteria
- **Active Backlogs:** Maximum 1 backlog allowed at time of application
- **Gap Years:** Max 2 years gap in education acceptable with valid reason
- **Age Limit:** None (open to all eligible candidates)
- **Nationality:** Indian residents only
- **Application:** Can apply **only once per year** (duplicate profiles rejected)

### Batch Eligibility
- Current year graduates (e.g., 2026 batch in 2026)
- Previous year graduates (e.g., 2025 batch can still apply in 2026 if not placed)

#### Detailed Topic Coverage

##### 1. Number Systems
**Concepts:**
- Divisibility rules (2, 3, 4, 5, 6, 8, 9, 10, 11)
- Prime numbers, composite numbers
- Factors and multiples
- Unit digit problems
- Remainder theorem
- Digit sum problems

**Question Types:**
- Find the unit digit of 7^203
- How many numbers between 1-100 are divisible by both 3 and 5?
- What is the remainder when 2^50 is divided by 7?

**Formulas:**
```
Number of factors = (a+1)(b+1)(c+1) where N = p^a × q^b × r^c
Sum of factors = [(p^(a+1) - 1)/(p-1)] × [(q^(b+1) - 1)/(q-1)]
```

---

##### 2. Percentages
**Concepts:**
- Basic percentage calculations
- Percentage increase/decrease
- Successive percentage changes
- Conversion between fractions, decimals, percentages
- Reverse percentage (finding original value)

**Question Types:**
- If price increased by 20%, by what % should consumption decrease to keep expenditure same?
- A number increased by 25% and then decreased by 20%. What is net change?
- Population of a town is 50,000. If it increases by 10% in year 1 and 20% in year 2, find final population.

**Formulas:**
```
Percentage = (Part/Whole) × 100
Increase % = [(New - Old)/Old] × 100
Successive change = a + b + (ab/100) where a, b are individual changes
If price increases by r%, consumption should decrease by [r/(100+r)] × 100%
```

---

##### 3. Profit & Loss
**Concepts:**
- Cost Price (CP), Selling Price (SP), Marked Price (MP)
- Profit %, Loss %
- Discount calculations
- Successive discounts
- False weight/measure problems
- Partnership and profit sharing

**Question Types:**
- A shopkeeper marks goods 40% above CP and gives 20% discount. Find profit %.
- If SP of 10 articles = CP of 12 articles, find profit %.
- Two successive discounts of 20% and 30%. What is equivalent single discount?

**Formulas:**
```
Profit = SP - CP
Profit % = (Profit/CP) × 100
Loss % = (Loss/CP) × 100
Discount = MP - SP
Discount % = (Discount/MP) × 100
If SP = CP, then Profit/Loss = 0
Successive discounts: Total = a + b - (ab/100)
```

---

##### 4. Time & Work
**Concepts:**
- Work done by individuals in given time
- Combined work (working together)
- Work efficiency
- Pipes and cisterns
- Alternate day work
- Work and wages (payment distribution)

**Question Types:**
- A can do work in 10 days, B in 15 days. In how many days together?
- A and B working together complete in 12 days. If A alone takes 20 days, find B's time.
- Pipe A fills tank in 6 hours, pipe B empties in 8 hours. If both open, time to fill?

**Formulas:**
```
Work = Time × Efficiency
Total work = LCM of individual times (assumption method)
If A does work in 'a' days, B in 'b' days:
  Together = (a×b)/(a+b) days
Efficiency ∝ 1/Time
```

---

##### 5. Time, Speed & Distance
**Concepts:**
- Basic speed-distance-time
- Relative speed (same/opposite direction)
- Trains crossing problems
- Boats and streams
- Average speed
- Races and games

**Question Types:**
- Train 240m long passes a pole in 24 seconds. Find speed.
- Two trains of length 200m and 300m running at 60 km/h and 40 km/h in opposite directions. Time to cross?
- A man rows 15 km upstream in 3 hours and 22 km downstream in 2 hours. Find speed of stream.

**Formulas:**
```
Speed = Distance/Time
Distance = Speed × Time
Time = Distance/Speed
Relative Speed (opposite) = S1 + S2
Relative Speed (same) = |S1 - S2|
Train crossing: Time = (L1 + L2)/Relative Speed
Boat: Upstream = Boat - Stream, Downstream = Boat + Stream
```

---

##### 6. Simple & Compound Interest
**Concepts:**
- Simple Interest (SI)
- Compound Interest (CI)
- Difference between SI and CI
- Population growth/depreciation
- Installment problems

**Question Types:**
- Find SI on ₹5000 at 10% per annum for 3 years.
- On what sum does CI for 2 years at 5% amount to ₹1025?
- Difference between CI and SI on ₹10,000 for 2 years at 10% p.a.?

**Formulas:**
```
SI = (P × R × T)/100
Amount = P + SI
CI = P[(1 + R/100)^T - 1]
Difference (CI - SI) for 2 years = P(R/100)^2
```

---

##### 7. Averages
**Concepts:**
- Mean, median, mode
- Weighted average
- Average speed
- Age-based averages
- Replacement/addition in averages

**Question Types:**
- Average of 10 numbers is 50. If one number (60) is replaced by 80, find new average.
- Average age of 30 students is 15 years. If teacher's age (45) included, find new average.
- A car travels 60 km at 40 km/h and 40 km at 60 km/h. Find average speed.

**Formulas:**
```
Average = Sum of observations / Number of observations
If avg of n numbers is x, sum = n × x
Average speed = Total distance / Total time (NOT average of speeds)
```

---

##### 8. Ratio & Proportion
**Concepts:**
- Simplifying ratios
- Compounding ratios
- Duplicate/triplicate ratios
- Direct and inverse proportion
- Partnership (ratio-based profit sharing)
- Mixture problems

**Question Types:**
- If A:B = 2:3 and B:C = 4:5, find A:B:C
- Divide ₹1500 among A, B, C in ratio 2:3:5
- Two partners A and B invest ₹20,000 and ₹30,000 for 6 and 8 months. Share profit of ₹15,000.

**Formulas:**
```
a:b = a/b
If a:b = c:d, then ad = bc (cross multiplication)
Compounding: If a:b = m:n and b:c = p:q, then a:b:c = mp:np:nq
Profit sharing = Capital × Time
```

---

##### 9. Mixtures & Alligations
**Concepts:**
- Mixture of two or more components
- Alligation rule (ratio calculation)
- Replacement of mixture
- Repeated dilution

**Question Types:**
- In what ratio should ₹60/kg rice be mixed with ₹40/kg rice to get mixture worth ₹50/kg?
- A vessel contains 60L mixture of milk and water in 7:5 ratio. How much water to add to make ratio 7:9?

**Formulas:**
```
Alligation Rule:
If two quantities mixed to get mean price M:
  (Cheaper quantity) : (Dearer quantity) = (D - M) : (M - C)
Where C = cheaper price, D = dearer price, M = mean price
```

##### 11. LCM & HCF
**Concepts:**
- Prime factorization method
- Division method
- LCM and HCF of fractions
- Problems involving bells, lights, rotations
- Maximum/minimum group size problems

**Question Types:**
- Find LCM and HCF of 12, 18, 24
- Three bells toll at intervals of 9, 12, 15 minutes. If they toll together at 8 AM, when next?
- Find greatest number that divides 43, 91, 183 leaving same remainder.

**Formulas:**
```
LCM × HCF = Product of two numbers
LCM of fractions = LCM of numerators / HCF of denominators
HCF of fractions = HCF of numerators / LCM of denominators
```

##### 12. Number Series
**Concepts:**
- Arithmetic progression (AP)
- Geometric progression (GP)
- Squares, cubes series
- Prime number series
- Alternate series
- Mixed series (two-tier patterns)

**Question Types:**
- Find next term: 2, 6, 12, 20, 30, ?
- Find missing: 3, 7, 15, ?, 63, 127
- Pattern: 2, 5, 11, 23, 47, ? (each term = 2×previous + 1)

**Common Patterns:**
```
AP: a, a+d, a+2d, ... (constant difference)
GP: a, ar, ar^2, ... (constant ratio)
Squares: 1, 4, 9, 16, 25 (n^2)
Cubes: 1, 8, 27, 64, 125 (n^3)
Prime gaps: 2, 3, 5, 7, 11, 13
```

---

##### 13. Permutations & Combinations
**Concepts:**
- Factorial notation
- Permutations (arrangement)
- Combinations (selection)
- Circular permutations
- Restricted permutations

**Question Types:**
- In how many ways can 5 people sit in a row?
- From 10 people, select a committee of 4. How many ways?
- How many 4-digit numbers can be formed using 1,2,3,4,5 without repetition?

**Formulas:**
```
n! = n × (n-1) × (n-2) × ... × 1
nPr = n!/(n-r)!
nCr = n!/[r!(n-r)!]
Circular permutation = (n-1)!
```

---

##### 14. Probability
**Concepts:**
- Basic probability definition
- Coin, dice, card problems
- Independent events
- Mutually exclusive events
- Conditional probability (basic)

**Question Types:**
- Two dice thrown. Probability of sum = 7?
- From a deck of 52 cards, one card drawn. Probability of getting a king?
- A bag has 5 red, 3 blue balls. Probability of drawing 2 red balls?

**Formulas:**
```
Probability = Favorable outcomes / Total outcomes
P(A or B) = P(A) + P(B) - P(A and B)
P(A and B) = P(A) × P(B) [if independent]
P(not A) = 1 - P(A)
```

##### 2. Error Identification
**Common Error Types:**
1. **Subject-Verb Agreement**
   - "The team have won" → "The team has won"
   
2. **Tense Consistency**
   - "He comes yesterday" → "He came yesterday"
   
3. **Article Usage**
   - "I saw a elephant" → "I saw an elephant"
   
4. **Preposition Errors**
   - "Good in mathematics" → "Good at mathematics"
   
5. **Pronoun-Antecedent Agreement**
   - "Everyone must do their work" → "Everyone must do his/her work"
   
6. **Comparison Errors**
   - "More taller" → "Taller" or "More tall"

**Question Example:**
"Everyday life have become / more complicated with the / advancement in mobile technology / No error"

**Answer:** Error in Part B ("have" should be "has")

**Approach:**
1. Identify the opening sentence (usually introduces topic)
2. Look for pronouns and references
3. Find logical connectors (however, therefore, moreover)
4. Check time sequence

```
Correct Order: B → D → A → C
```

##### 2. Blood Relations
**Common Relations:**
```
Father's/Mother's brother = Uncle
Father's/Mother's sister = Aunt
Brother's/Sister's son = Nephew
Brother's/Sister's daughter = Niece
Husband's/Wife's brother = Brother-in-law

```

##### 3. Coding-Decoding
**Types:**
1. **Letter Shifting**
   - CAT → DBU (each letter +1)
   
2. **Reverse Coding**
   - DELHI → IHLED (reverse order)
   
3. **Number Coding**
   - A=1, B=2, C=3... → CAT = 3,1,20
   
4. **Mixed Patterns**
   - Vowels +2, Consonants -1

**Example:**
"If MOBILE is coded as NPCJMF, how is PRINTER coded?"

**Pattern:** Each letter +1
**Answer:** QSJOUFS

##### 4. Syllogisms
**Rules:**
- All A are B + All B are C → All A are C (valid)
- Some A are B + All B are C → Some A are C (valid)
- No A are B + All B are C → No A are C (valid)

**Question:**
```
Statements:
1. All managers are leaders.
2. Some leaders are intelligent.

Conclusions:
I. All managers are intelligent.
II. Some intelligent are leaders.

Answer: Only II follows
```

**Common Errors:**
- Don't assume reverse ("All A are B" ≠ "All B are A")
- "Some" ≠ "All"
- Use Venn diagrams for complex cases

##### 5. Data Sufficiency
**Question Format:**
```
Question: What is the age of Ravi?

Options:
1. Statement A alone is sufficient
2. Statement B alone is sufficient
3. Both A and B together are sufficient ✓
4. Neither A nor B is sufficient
5. Either A or B alone is sufficient
```

#### Coding Pattern Examples

```
Problem: Find the element that appears odd number of times

- Use XOR (a ^ a = 0)
- All pairs cancel out, odd occurrence remains
```

```

Approach:
- Divide by 2 until odd
- Check odd numbers from 3 to √N
- If N > 1 after loop, N is a prime factor
```

## 8. Selection Process

### Round 1: TCS NQT (Online Assessment)
**Duration:** 190 minutes (Foundation 75 min + Advanced 115 min)
**Sections:** Aptitude, Verbal, Reasoning, Coding
**Mode:** Online proctored (webcam + screen share mandatory)
**Eligibility:** Foundation must be cleared to be eligible for next rounds

### Round 2: Technical + Managerial Interview (Combined Panel)
**Duration:** 30-45 minutes
**Focus Areas:**

1. **Resume Discussion (5 min)**
   - Projects explained
   - Technologies used
   - Your role and contribution

2. **Coding (15-20 min)**
   - 1-2 live coding problems (Easy-Medium)
   - Code on paper/whiteboard/laptop
   - Topics: Arrays, strings, basic DSA

#### Problem 1 (Easy): Array Manipulation

**Title:** Find Second Largest Element

**Description:**
Given an array of integers, find the second largest element. If the second largest element doesn't exist, return -1.

**Input:**
```
arr = [12, 35, 1, 10, 34, 1]
```

**Output:**
```
34
```

**Explanation:** The largest element is 35, second largest is 34.

**Constraints:**
- 1 ≤ arr.length ≤ 10^5
- -10^9 ≤ arr[i] ≤ 10^9

**Starter Code (Python):**
```python
def findSecondLargest(arr):
    # Write your code here
    pass

# Test
arr = [12, 35, 1, 10, 34, 1]
print(findSecondLargest(arr))  # Expected: 34
```

**Solution:**
```python
def findSecondLargest(arr):
    if len(arr) < 2:
        return -1
    
    first = second = float('-inf')
    
    for num in arr:
        if num > first:
            second = first
            first = num
        elif num > second and num != first:
            second = num
    
    return second if second != float('-inf') else -1
```

**Time Complexity:** O(n)  
**Space Complexity:** O(1)

#### Problem 2 (Easy-Medium): String Manipulation

**Title:** Check if String is Palindrome (Ignore Non-Alphanumeric)

**Description:**
Given a string s, determine if it is a palindrome, considering only alphanumeric characters and ignoring cases.

**Input:**
```
s = "A man, a plan, a canal: Panama"
```

**Output:**
```
true
```

**Explanation:** "amanaplanacanalpanama" is a palindrome.

**Constraints:**
- 1 ≤ s.length ≤ 10^5
- s consists of printable ASCII characters

**Starter Code (Python):**
```python
def isPalindrome(s):
    # Write your code here
    pass

# Test
s = "A man, a plan, a canal: Panama"
print(isPalindrome(s))  # Expected: True
```

**Solution:**
```python
def isPalindrome(s):
    # Filter and convert to lowercase
    filtered = ''.join(c.lower() for c in s if c.isalnum())
    
    # Two-pointer approach
    left, right = 0, len(filtered) - 1
    
    while left < right:
        if filtered[left] != filtered[right]:
            return False
        left += 1
        right -= 1
    
    return True
```

**Time Complexity:** O(n)  
**Space Complexity:** O(n) for filtered string

#### Problem 3 (Medium): Array Problem

**Title:** Find All Pairs with Given Sum

**Description:**
Given an array of integers and a target sum, find all unique pairs of elements that add up to the target sum.

**Input:**
```
arr = [1, 5, 7, -1, 5]
target = 6
```

**Output:**
```
[(1, 5), (7, -1)]
```

**Explanation:** 1+5=6 and 7+(-1)=6. Note: (5,1) is same as (1,5).

**Constraints:**
- 2 ≤ arr.length ≤ 10^4
- -10^9 ≤ arr[i] ≤ 10^9
- -10^9 ≤ target ≤ 10^9

**Starter Code (Python):**
```python
def findPairs(arr, target):
    # Write your code here
    pass

# Test
arr = [1, 5, 7, -1, 5]
target = 6
print(findPairs(arr, target))  # Expected: [(1, 5), (7, -1)]
```

**Solution:**
```python
def findPairs(arr, target):
    seen = set()
    pairs = set()
    
    for num in arr:
        complement = target - num
        if complement in seen:
            # Add as tuple in sorted order to avoid duplicates
            pair = tuple(sorted([num, complement]))
            pairs.add(pair)
        seen.add(num)
    
    return list(pairs)
```

**Time Complexity:** O(n)  
**Space Complexity:** O(n)

#### Problem 4 (Medium): Mathematical

**Title:** Find All Prime Factors

**Description:**
Given a positive integer n, return all its prime factors in ascending order.

**Input:**
```
n = 60
```

**Output:**
```
[2, 2, 3, 5]
```

**Explanation:** 60 = 2 × 2 × 3 × 5

**Constraints:**
- 2 ≤ n ≤ 10^9

**Starter Code (Python):**
```python
def primeFactors(n):
    # Write your code here
    pass

# Test
n = 60
print(primeFactors(n))  # Expected: [2, 2, 3, 5]
```

**Solution:**
```python
def primeFactors(n):
    factors = []
    
    # Handle 2 separately
    while n % 2 == 0:
        factors.append(2)
        n //= 2
    
    # Check odd factors from 3 onwards
    i = 3
    while i * i <= n:
        while n % i == 0:
            factors.append(i)
            n //= i
        i += 2
    
    # If n > 1, then it's a prime factor
    if n > 1:
        factors.append(n)
    
    return factors
```

**Time Complexity:** O(√n)  
**Space Complexity:** O(log n) for storing factors
