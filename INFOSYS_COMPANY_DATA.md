##### 2. Time & Work

**Concepts:**
- Individual and combined work
- Work efficiency
- Pipes and cisterns
- Work and wages
- LCM method

**Sample Question:**
```
Q: A can complete a work in 12 days and B in 18 days. They work together for 4 days, 
then A leaves. In how many more days will B complete the remaining work?

A) 8 days    B) 10 days    C) 12 days    D) 6 days

Solution:
A's 1 day work = 1/12
B's 1 day work = 1/18
Together 1 day = 1/12 + 1/18 = (3+2)/36 = 5/36

Work done in 4 days = 4 × 5/36 = 20/36 = 5/9
Remaining work = 1 - 5/9 = 4/9

B alone completes 4/9 work in: (4/9)/(1/18) = (4/9) × 18 = 8 days

Answer: A
```

#### Sample Questions

##### Type 1: Trace & Output

```
Q: What is the output of the following pseudo code?

Integer a, b, c
Set a = 5, b = 10, c = 15
if((a + c) < (c - b))
    a = (b + c) + c
else
    b = b + a
end if
Print a + b + c

A) 35    B) 45    C) 40    D) 50

Solution:
Step 1: a = 5, b = 10, c = 15
Step 2: Check condition: (5 + 15) < (15 - 10) → 20 < 5 → False
Step 3: Execute else: b = 10 + 5 = 15
Step 4: a = 5, b = 15, c = 15
Step 5: Print 5 + 15 + 15 = 35

Answer: A
```

---

##### Type 2: Loop Tracing

```
Q: What is the output?

Integer i, sum = 0
for(i = 1; i < 6; i = i + 2)
    sum = sum + i
end for
Print sum

A) 9    B) 15    C) 6    D) 10

Solution:
Iteration 1: i = 1, sum = 0 + 1 = 1
Iteration 2: i = 3, sum = 1 + 3 = 4
Iteration 3: i = 5, sum = 4 + 5 = 9
Loop exits (i = 7 > 6)

Answer: A
```

##### Type 3: Array Operations


##### Problem 1 (Easy): Array Manipulation

```
Title: Find Second Maximum Element

Description:
Given an array of integers, find the second largest element. If it doesn't exist, return -1.

Input:
arr = [12, 35, 1, 10, 34, 1]

Output:
34

Explanation:
Largest = 35, Second Largest = 34

Constraints:
- 1 ≤ n ≤ 10^5
- -10^9 ≤ arr[i] ≤ 10^9

Starter Code (Python):
def findSecondMax(arr):
    # Write your code here
    pass

Test Cases:
Input: [12, 35, 1, 10, 34, 1]
Output: 34

Input: [10, 10, 10]
Output: -1

Input: [5, 2]
Output: 2
```

**Solution:**
```python
def findSecondMax(arr):
    if len(arr) < 2:
        return -1
    
    first = second = float('-inf')
    
    for num in arr:
        if num > first:
            second = first
            first = num
        elif num > second and num != first:
            second = num
    
    return second if second != float('-inf') else -1

# Time: O(n), Space: O(1)
```

##### Problem 2 (Medium): String Problem

```
Title: Longest Substring Without Repeating Characters

Description:
Given a string s, find the length of the longest substring without repeating characters.

Input:
s = "abcabcbb"

Output:
3

Explanation:
The longest substring is "abc" with length 3.

Constraints:
- 0 ≤ s.length ≤ 5 * 10^4
- s consists of English letters, digits, symbols, and spaces

Starter Code (Python):
def lengthOfLongestSubstring(s):
    # Write your code here
    pass

Test Cases:
Input: "abcabcbb"
Output: 3

Input: "bbbbb"
Output: 1

Input: "pwwkew"
Output: 3 (substring "wke")
```

**Solution:**
```python
def lengthOfLongestSubstring(s):
    char_set = set()
    left = 0
    max_length = 0
    
    for right in range(len(s)):
        while s[right] in char_set:
            char_set.remove(s[left])
            left += 1
        
        char_set.add(s[right])
        max_length = max(max_length, right - left + 1)
    
    return max_length

# Time: O(n), Space: O(min(n, m)) where m = charset size
```

```
You are given an array of integers. You need to select elements such that:

Input:
arr = [2, -3, 4, -5, 6]

Output:
7
```

```
Title: Multi-Constraint Dynamic Programming

You have n items, each with weight w[i] and value v[i]. You have two knapsacks with 
capacities W1 and W2. Each item can go into either knapsack (or neither). 
Maximize total value.

Constraints:
- 1 ≤ n ≤ 100
- 1 ≤ W1, W2 ≤ 1000
- 1 ≤ w[i], v[i] ≤ 1000

Approach: 3D DP
dp[i][w1][w2] = max value using first i items with capacities w1, w2 remaining

Time: O(n × W1 × W2)
Space: O(n × W1 × W2) or O(W1 × W2) with space optimization
```

## 9. Sample Questions by Topic

### 9.1 Quantitative Aptitude Questions

#### Q1: Percentages

```
If a shopkeeper marks his goods 30% above cost price and gives a discount of 10%, 
what is his profit percentage?

A) 17%    B) 20%    C) 15%    D) 18%

Solution:
Let CP = 100
MP = 100 + 30% = 130
Discount = 10% of 130 = 13
SP = 130 - 13 = 117
Profit = 117 - 100 = 17
Profit % = 17%

Answer: A
```

---

#### Q2: Time & Work

```
A and B together can complete a work in 8 days. B alone can complete it in 12 days. 
In how many days can A alone complete the work?

A) 20 days    B) 24 days    C) 16 days    D) 18 days

Solution:
(A + B)'s 1 day work = 1/8
B's 1 day work = 1/12

A's 1 day work = 1/8 - 1/12 = (3-2)/24 = 1/24

A alone = 24 days

Answer: B
```

---

### 9.2 Logical Reasoning Questions

#### Q3: Syllogism

```
Statements:
1. Some engineers are doctors.
2. All doctors are intelligent.

Conclusions:
I. Some engineers are intelligent.
II. All intelligent are doctors.

A) Only I follows
B) Only II follows
C) Both follow
D) Neither follows

Solution:
- Conclusion I: True (Some engineers → doctors → intelligent)
- Conclusion II: False (reverse statement not valid)

Answer: A
```

---

#### Q4: Puzzle

```
In a family of 6 persons A, B, C, D, E, F:
- There are two married couples
- B is the grandmother of F
- F is the daughter of D
- C is the son of A
- E is the brother of F

How is A related to E?

A) Mother    B) Father    C) Uncle    D) Grandfather

Solution:
- B is grandmother of F
- F is daughter of D → D is parent of F
- E is brother of F → E and F are siblings, D is parent of E too
- C is son of A → A is parent of C
- Since there are 2 married couples and B is grandmother:
  - Generation 1: B and spouse
  - Generation 2: D and spouse (A)
  - Generation 3: E, F, C

A is parent of C, and also parent of D's spouse or is D's spouse.
If D married someone, and A is D's spouse, then A is mother/father of E.

Answer: A (Mother) or B (Father) - depends on gender assumption
Typically answer is A (Mother) in such questions.
```

### 9.4 Pseudo Code Questions

#### Q7: Code Tracing

```
Integer a = 10, b = 20, c = 30
if((a + b) > c)
    c = (a + b) - c
else
    c = (a - b) + c
end if
Print c

A) 0    B) 30    C) 20    D) 40

Solution:
Condition: (10 + 20) > 30 → 30 > 30 → False
Execute else: c = (10 - 20) + 30 = -10 + 30 = 20

Answer: C
```

### Section-Wise Strategy

#### Quantitative Aptitude Strategy

**Time Management:**
- Easy questions (6-7 Q): 2 min each = 12-14 min
- Medium questions (2-3 Q): 4 min each = 8-12 min
- Hard questions (1 Q): Skip if stuck beyond 5 min
- **Total:** 25-30 min (save 5-10 min buffer)

**Approach:**
1. Skim all 10 questions first (1 min)
2. Solve Easy ones immediately
3. Attempt Medium ones next
4. Return to Hard if time permits
5. Mark educated guesses (no negative marking)

---

#### Logical Reasoning Strategy (Hardest Section)

**Time Management:**
- Syllogisms (3 Q): 1.5 min each = 4.5 min
- Puzzles (3 Q): 2-3 min each = 6-9 min (can take longer if complex)
- DI (3 Q): 1.5 min each = 4.5 min
- Others (6 Q): 1 min each = 6 min
- **Total:** 21-24 min (1 min buffer)

**Approach:**
1. **DO NOT spend >3 min on any single question**
2. Start with Series/Coding (easiest)
3. Then Syllogisms (practice makes perfect)
4. Skip ultra-complex puzzles initially
5. Return to skipped questions if time left
6. Use elimination technique aggressively

**Common Mistake:** Getting stuck on one hard puzzle for 10 minutes and losing the section.

---

#### Verbal Ability Strategy

**Time Management:**
- Reading Comprehension (8-10 Q): 12-15 min (includes reading passage)
- Grammar/Sentence Correction (4 Q): 4-5 min
- Para Jumbles (3 Q): 3-4 min
- Synonyms/Antonyms (3 Q): 2-3 min
- **Total:** 21-27 min

**Approach:**
1. Read RC passage once, carefully (4-5 min)
2. Solve RC questions with passage reference (8-10 min)
3. Solve Grammar questions (quick wins)
4. Attempt Para Jumbles
5. Synonyms last (either you know or you don't)

---

#### Pseudo Code Strategy (Most Unique)

**Time Management:**
- 2 min per question maximum
- **Total:** 10 min for 5 questions

**Approach:**
1. Read question completely
2. Trace code line by line on rough paper
3. Track variable values in a table
4. Don't rush - accuracy matters more than speed
5. Double-check array indexing (common mistake)
6. Verify loop conditions (off-by-one errors)

**Pro Tip:** Even 3/5 correct is a GREAT score in Pseudo Code.

---

#### Coding Strategy

**Time Management:**
- Problem 1 (Easy): 15-20 min
- Problem 2 (Medium): 30-35 min
- Testing: 5-8 min
- **Total:** 58 min

**Approach:**
1. Read both problems first (3 min)
2. Identify easier one, solve first
3. Write brute force solution, then optimize
4. Test with visible test cases
5. Handle edge cases (empty input, single element, large input)
6. Submit when confident
7. Attempt second problem
8. Partial credit is fine (passing some test cases)
